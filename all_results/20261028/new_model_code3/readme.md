这四组使用**完全相同的807条Query，ID和真实标签一致**。目前结果是：**Sinkhorn 3000 terms的DL3准确率最高；1000 terms更省时；WMD没有超过这两组Sinkhorn。**

共同设置是均等权重、Lookahead、最终Top-4、`gate=gold`。三组OT方法均由Centroid初筛Top-8；两组Sinkhorn都是 **`reg=0.05`**。

分类实际耗时包含在线读取预计算节点分布，不包含离线准备、启动加载和Query预处理。CPU时间与实际耗时不相加。

需要注意，**3000 terms开启了分段计时 `profile_ot`，1000 terms没有开启**，所以两者耗时不是完全相同的测量条件。3000 terms平均每条读取节点分布约 **3.12秒**，1000 terms约 **0.85秒**，分布加载是明显开销。

**当前建议：用Sinkhorn 1000 terms作为效率优先的配置。** 它比CPU WMD约快2.86倍，准确率也略高；3000 terms适合追求目前最高DL3准确率，但只增加3条Top-1正确预测，完整路径仍为66条。

另外，`gate=gold`允许前层真实类别进入Top-4后继续，所以 **DL3 Top-1正确125条，不等于三层Top-1全对125条**；后者是66条。
